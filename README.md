# Clínica Dental Care

Página web estática en español para Clínica Dental Care, Dra. Jissell Hernández.

## Archivos

- `index.html`: página completa, estilos adaptables a teléfono y computadora, menú móvil, preguntas frecuentes y formulario de solicitud de cita.
- `assets/dra-jissell-hernandez.jpg`: recorte del retrato incluido en el anuncio que compartiste.

## Solicitudes de cita

El formulario prepara en WhatsApp un mensaje con el nombre, número de contacto, tratamiento de interés y fecha/horario preferidos. La persona debe revisar y enviar el mensaje; la clínica confirma la disponibilidad en la conversación. Esta página no guarda datos ni administra un calendario.

El número está configurado como `+505 8541-9792`. Para cambiarlo, actualiza el número en los enlaces `tel:` y `wa.me` y el valor `clinicWhatsApp` dentro de `index.html`.

## Publicar con GitHub Pages

1. Sube `index.html` y la carpeta `assets` al directorio que publica el sitio (normalmente la raíz de la rama configurada).
2. En el repositorio, abre **Settings → Pages** y confirma la rama y carpeta de publicación.
3. Abre la dirección que GitHub Pages muestre al terminar la publicación.

Mantén `assets/dra-jissell-hernandez.jpg` junto a `index.html` dentro de la carpeta `assets`; la página usa esa ruta relativa.

## Datos que conviene confirmar

El anuncio da como referencia “Frente al Tabernáculo Triunfadores en Cristo”, pero no especifica municipio, horario, correo ni enlace de mapa exacto. La página no inventa esos datos; el enlace de Maps busca la referencia en Nicaragua. Confirma el municipio y el punto exacto para reemplazar ese enlace por una ubicación precisa.

El enlace y el botón flotante de WhatsApp apuntan al número indicado en el anuncio. Confirma que el número tenga WhatsApp habilitado antes de publicar.
